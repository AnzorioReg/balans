# Напоминания в Баланс

## Как работают напоминания

Приложение использует локальные уведомления Android (AlarmManager + BroadcastReceiver).

### Возможности
- Создание, редактирование и удаление напоминаний.
- Повторяющиеся напоминания (ежедневно, по дням недели).
- Действия из уведомления (открыть приложение, отметить выполненным).
- Сохранение после перезагрузки устройства.

### Техническая реализация
- `ReminderScheduler` — планирование и отмена.
- `ReminderReceiver` — обработка срабатывания.
- `ReminderBridge` — JS-интерфейс из WebView.
- `ReminderSchedule` — модель расписания.

### Разрешения
- `SCHEDULE_EXACT_ALARM` (Android 12+)
- `POST_NOTIFICATIONS` (Android 13+)
- `RECEIVE_BOOT_COMPLETED`

### Ограничения
- На некоторых производителях (Xiaomi, Huawei и др.) могут требоваться дополнительные настройки автозапуска.
- Точные будильники зависят от режима энергосбережения.
