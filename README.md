# Баланс

Android-приложение для здоровья. Рабочий репозиторий и память проекта: `AnzorioReg/balans`.

## Начало работы

Перед работой прочитать:

1. [AGENTS.md](AGENTS.md) — правила работы и согласования действий.
2. [docs/STATUS.md](docs/STATUS.md) — текущее состояние, подтверждённое и непроверенное.
3. [docs/DECISIONS.md](docs/DECISIONS.md) — подтверждённые решения и история перехода между репозиториями.

Правила не дублируются здесь: их основной источник — `AGENTS.md`.

## Структура

- `app/` — Android-проект: конфигурация, Java/Kotlin, ресурсы, встроенный HTML и модульные тесты.
- `web-src/` — исходники веб-интерфейса, сборщик HTML и браузерные сценарии проверки.
- `gradle/wrapper/`, `gradlew`, `gradlew.bat` — Gradle Wrapper.
- `sources.js` — файл из исходного комплекта; его назначение следует уточнять по содержимому перед изменением.
- `docs/` — состояние и подтверждённые решения проекта.

Исходники из комплекта `BalansAndroid` размещены непосредственно в корне репозитория, без дополнительного каталога `BalansAndroid/`. README из архива не переносился: этот документ служит входной страницей репозитория.

## Технические документы

- [FLOWS.md](FLOWS.md) — сценарии проверки версий 1.15 и 1.16; не свидетельство их повторного выполнения после переноса.
- [README_REMINDERS.md](README_REMINDERS.md) — описание Android-интеграции напоминаний и её ограничений; доставка на телефоне после переноса не проверена.
- [VALIDATION.md](VALIDATION.md) — прежний отчёт комплекта о проверках от 31 октября 2026 года и команды повторения. Это не отчёт о новых запусках из данного репозитория.

## Состояние на 2 ноября 2026 года

По присланному манифесту найдены все 110 ожидаемых файлов проекта, кроме намеренно исключённого README из архива. Дополнительно сохранены четыре документа памяти проекта. Подтверждены наличие `gradle/wrapper/gradle-wrapper.jar` размером 43 453 байта и одинаковые Git blob SHA двух HTML: `web-src/index.html` и `app/src/main/assets/index.html`.

Сверка путей не доказывает побайтового совпадения всего проекта с исходным ZIP. После переноса сборка, тесты и проверки на физическом телефоне не выполнялись.

В комплекте отсутствуют `generate-identity.py` и `qa-integrations.js`, ранее упомянутые в документации. Команду `node qa-integrations.js` из исторического отчёта сейчас выполнить нельзя без получения отсутствующего файла. Не создавать замену догадками и не считать прежние проверки повторно подтверждёнными.

## Последующие действия

Сборка, тесты, исправления кода и обновление APK — отдельные этапы, требующие согласования по `AGENTS.md`. При изменении веб-исходников учитывать перенос собранного HTML в Android assets. Сведения о версии, подписи и ограничениях проверки находятся в `docs/STATUS.md`.
