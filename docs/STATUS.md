Обновлено: 2026-11-02.

## Исходная точка

Предоставленный Анзором комплект исходников называется `BalansAndroid`.
По прежней проверке комплекта заявленная версия — 1.16:
`versionName "1.16"`, `versionCode 16`, пакет `com.anzor.balans`.
В рамках переноса эти значения повторно по содержимому файла не проверялись.

Исходники перенесены в корень нового репозитория, без внешнего каталога
`BalansAndroid/`. Прежний рабочий репозиторий — `anzornikoli-commits/balans`;
история решения о переходе сохранена в `docs/DECISIONS.md`.

## Устройство приложения

По описанию и прежнему чтению отдельных файлов комплекта интерфейс
находится в `web-src`. Скрипт `web-src/build.py` объединяет `src.html`
и модули в `web-src/index.html`. Для Android готовый HTML помещается
в `app/src/main/assets/index.html`.

`MainActivity.java` загружает встроенный HTML в WebView и подключает
интерфейсы для Health Connect, Bluetooth, напоминаний, оформления и
сохранения/отправки файлов. Прежняя заготовка «Рядом» не является
актуальной основой проекта.

## Наблюдения из прежней проверки исходников

Следующие сведения перенесены из предыдущего STATUS, а не получены
повторным аудитом текущего кода после загрузки:

- В `ui.js` обнаружены настройки карточек, верхнего блока, выбора
  показателей, размеров, сворачивания и перемещения.
- В `BleBridge.java` обнаружены BLE-поиск, разрешения, подключение,
  чтение и подписка на стандартные характеристики, обработка ошибок
  и отключение при уходе в фон.
- В `HealthBridge.kt` обнаружены разрешения Health Connect, чтение
  показателей и истории до 366 дней с учётом доступного диапазона,
  суточное агрегирование и отмена чтения при сворачивании.
- В `health-cache.js` обнаружены история в IndexedDB, загрузка
  сохранённых данных и резервный вариант хранения.
- В `reminders.js` обнаружен вызов Android-интерфейса напоминаний.
  Наличие кода не подтверждает доставку уведомлений на телефоне.
- `build.py` создаёт веб-HTML, но сам по себе не копирует его в assets.

Это наблюдения по отдельным файлам, не полный аудит и не проверка
выполнения функций на физическом телефоне.

## Известные вопросы

- `generate-identity.py` и `qa-integrations.js` отсутствуют в присланном
  списке ZIP и перенесённом комплекте, хотя ранее упоминались
  в документации. Команда `node qa-integrations.js` в прежнем
  `VALIDATION.md` не выполнима без отсутствующего файла.
  Не придумывать замену; происхождение и необходимость файлов нужно уточнить.
- После изменения веб-исходников HTML в Android assets нужно обновить
  отдельно и снова сверить с веб-версией. Сейчас совпадение подтверждено
  только для состояния на момент проверки переноса.
- По одному `health-cache.js` нельзя определить весь сценарий резервного
  копирования, очистки и восстановления; связанную логику нужно проверить
  до вывода об ошибке.
- Ключ подписи не включён в исходный комплект согласно прежнему отчёту.
  Совместимость будущей сборки с установленным APK не проверена;
  не предлагать удаление приложения как обычный первый шаг.
