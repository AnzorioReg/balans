# Подтверждённые решения по проекту «Баланс»

Документ начат: 2026-11-01.

Здесь фиксируются решения Анзора. Предложения ИИ и неподтверждённые
идеи не записываются как решения владельца. Правила поведения ИИ
находятся в `AGENTS.md` и здесь не дублируются полностью.

## Название и репозиторий

**Решение Анзора, 2026-11-01:** приложение называется «Баланс».
Название «Рядом» было ошибочным и не является названием текущего
проекта. Рабочий репозиторий — `anzornikoli-commits/balans`.
Он создан заново, чтобы не смешивать историю проекта
с прежней Android-заготовкой.

Новая история репозитория не означает разработку приложения
с нуля: предоставленные доработанные исходники нужно сохранить.

## Единая память проекта

**Решение Анзора, 2026-11-01:** хранить код и актуальные документы
каждого проекта в отдельном репозитории GitHub. Документы должны
помогать разным ИИ-инструментам, которым Анзор предоставит доступ,
разобраться в текущем состоянии проекта.

Старые материалы могут оставаться доступными, но их нельзя
смешивать с актуальными неразмеченными копиями. Хранение файлов
на GitHub не означает, что любой ИИ автоматически их прочитает.

## Контроль действий ИИ

**Решение Анзора, 2026-11-01:** существенные изменения проекта
и обращения к другим ИИ-агентам требуют предварительного
объяснения и явного согласия. Перед возможным расходом кредитов,
денег или лимитов нужно предупредить; если стоимость неизвестна —
сказать об этом. Согласие на одну задачу не разрешает остальные.
Подробный порядок установлен в `AGENTS.md`.

## Один актуальный предпросмотр и APK

**Решение Анзора, 2026-11-01:** не создавать множество файлов
с разными «финальными» названиями. Поддерживать один актуальный
HTML-предпросмотр и один актуальный тестовый APK; историю
изменений исходников вести в Git.

Изменения интерфейса сначала показывать и проверять в HTML,
затем после законченного этапа при необходимости пересобирать APK.
Android-интеграции, включая Health Connect, Bluetooth и системные
напоминания, проверять в APK на телефоне: HTML этого не заменяет.

Постоянное имя APK не означает редактирование готового APK —
он пересобирается из исходников. Утверждённую стабильную версию
нельзя незаметно заменять непроверенной.

## Сохранение сделанного

**Решение Анзора, 2026-11-01:** исходить из предоставленного
доработанного комплекта «Баланса», в котором уже есть настройки
карточек, Bluetooth и другие возможности. Старый README проекта
«Рядом» не описывает текущее состояние приложения. Существующие
функции нельзя удалять или переделывать без согласования.

## Переход на новый аккаунт и размещение исходников

**Решение Анзора, 2026-11-02:** продолжать работу в `AnzorioReg/balans`.
Основание: указание перенести правила и материалы старого репозитория
в новый аккаунт и подтверждение создания и наполнения нового репозитория.
Адрес `anzornikoli-commits/balans` в решении от 1 ноября сохранён как
исторический; он больше не обозначает текущий рабочий репозиторий.

**Решение Анзора, 2026-11-02:** перенести 110 файлов комплекта
`BalansAndroid` с отображением `BalansAndroid/...` в корень репозитория,
исключив только README из архива. Основание: подтверждение манифеста
и последующая ручная загрузка пользователем через браузер.
Сохранить `AGENTS.md`, корневой `README.md`, `docs/DECISIONS.md`
и `docs/STATUS.md`; обновление документации согласуется отдельно.

**Решение Анзора, 2026-11-02:** актуализировать документацию после
переноса единым согласованным пакетом, не меняя код приложения и
действующие правила, кроме адреса рабочего репозитория.
Основание: просьба «Давай обновим всю документацию сразу» и согласие
с планом подготовки правок. Сборка, тесты и обращения к другим ИИ
этим решением не разрешены.
